# TARE — Tool Annotation Reuse, Exact

Code, results, and paper for **Pin and Replay, or Refuse: Exact Incremental Re-annotation Across Reference Database Releases**.

Reference databases such as Pfam publish a new release every few weeks to months, and each release forces a full re-search, even though most of the database has not changed (86.6% of Pfam entries were identical between 38.1 and 38.2). TARE wraps an unmodified search program and reruns it only on the entries that can matter. It pins the program's database-size setting to the new release, so the program itself prints the numbers a full run would print. It then tests the replay by adding back entries it left out, and if any output line changes it **refuses** and returns an ordinary full run.

Headline results (all from committed files under `pipeline/results/`):

- **3.47× faster** than a full rerun on Pfam 38.1→38.2 under the locked all-record bounded audit (median over 8 unflagged genomes; 95% CI 3.30–3.81). Status: `COMPLETE_CORRECT_CAMPAIGN`.
- Historical candidate-population timings on the same nine genomes: **4.24×** (Bernoulli) and **3.49×** (bounded s=299).
- **715,704 output lines** from HMMER and Infernal, none different from a full run.
- **Correct refusals** for DIAMOND (neighbor-entry filter) and BLAST+ (unpinned probe rows).
- Cost of checking vs unchecked replay: **1.58×** (C/B on the unflagged set).

Anonymous OSDI submission uses a distinct system name (**PARE**). This private repo and the arXiv/named build use **TARE**.

## Layout

```
pipeline/
  acts/           # the TARE implementation (Python package; `acts` is the pre-rename name)
  tests/          # unit tests
  scripts/        # experiment drivers and analysis
  jobs/           # CARC Slurm job scripts that produced the timing files
  results/        # committed measurements; every paper number cites one
  docs/           # protocols, red-team notes, related work
  paper/tare/     # the paper (main.tex, refs.bib, figures/, submission_pack/)
  artifact/       # artifact-evaluation image, laptop smokes, paper-number checker
  fixtures/       # small inputs used by tests and smokes
  egas/, contracts/  # earlier source-edit driver, kept for reference
tools/tare-console/  # local web console over pipeline/results and `acts run`
archive/          # early TARE paper draft and saved stale edits (not live)
```

## Quick start

Requires Python 3.10+ (3.11+ for the artifact checker). The artifact smokes also need HMMER 3.4 on `PATH`.

```bash
# Unit tests
./pipeline/run_tests.sh

# Check every number in the paper against the committed file it cites
python3 pipeline/artifact/check_paper_sources.py
# → mismatches=0

# Full artifact smoke path (a few minutes on a laptop)
./pipeline/artifact/kick_the_tires.sh

# Run console
python3 tools/tare-console/server.py
```

Artifact details, the Docker image, and the cluster jobs behind each timing number are in [`pipeline/artifact/README.md`](pipeline/artifact/README.md).
